# UniRoute SV 📍 (v2 - Edición Web)

**UniRoute SV** es una plataforma web interactiva diseñada para la consulta y optimización de rutas de transporte público y universitario en El Salvador.

---

## 🌐 Acceso a la Aplicación Web
Puedes acceder directamente a la versión desplegada sin necesidad de inicio de sesión:
- **Enlace Web:** `https://ideal-carnival-5vx7wrjxvgv63v9p4-8081.app.github.dev/`

---

## 🚀 Tecnologías Utilizadas
- **Framework:** React Native / React Native Web
- **Entorno de desarrollo:** Expo (SDK 54)
- **Lenguaje:** JavaScript (ES6+)
- **Mapas:** Integración Web Embed / OSM
- **Despliegue & Alojamiento:** GitHub Codespaces / Web Server

---

## 📋 Características Principales
- **Buscador interactivo:** Filtro en tiempo real por rutas, universidades y paradas clave.
- **Visualización de mapas:** Cobertura geográfica simplificada para entornos web sin dependencias nativas pesadas.
- **Detalle de rutas:** Consulta de trayectos principales (ej. Ruta 44, Ruta 30-B, áreas universitarias).
- **Diseño adaptativo:** Interfaz optimizada para computadoras y dispositivos móviles.
